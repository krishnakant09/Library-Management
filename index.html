Experiment 5 Reference & Viva Questions

        

          

            
1. What is DTD?

            
DTD (Document Type Definition) defines the legal building blocks, elements, attributes, and structural grammar of an XML document.

          

          

            
2. Well-Formed vs Valid XML

            
Well-Formed: Conforms to basic XML syntax (one root, tags closed, case-sensitive).

            Valid: Is well-formed AND adheres strictly to a DTD or XML Schema.

          

          

            
3. What is XSLT?

            
XSLT (Extensible Stylesheet Language Transformations) transforms XML data documents into HTML or other display formats using rule-based declarative templates.
